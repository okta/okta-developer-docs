After your integration is published in the OIN, you can track its performance and adoption through monthly usage reports. These reports provide a comprehensive view of how customers use your integrations.

#### What you need

* A published integration in the OIN
* A registered technical contact for the integration. Okta sends the monthly report email to this contact.
* Access to the Okta Integrator Free Plan org you used to submit your integration, so you can view the dashboard in the OIN Wizard

## Usage report metrics

The monthly usage report includes the following metrics for each published app:

| Metric | Description |
| ------ | ----------- |
| **Orgs using this app** | The number of customer orgs that use your app. |
| **Integrations built** | The number of integration capabilities that your app supports, compared to the total number of capabilities that Okta offers. For example, if your app supports Single Sign-On (SSO), Lifecycle Management (LCM), and a Workflows connector, the report shows that you've built 3 of 5 available integrations. |
| **Last updated** | The time since you last updated your app's OIN catalog listing. |

The report also tells you about new integration types that Okta recently added. Use this information to decide which capabilities to add to your integration. If you need help, contact Okta using the email address in the report email.

> **Note:** The data is refreshed once a month. The report covers the previous calendar month and excludes federal data, if any.

## Access your usage analytics

You can access your usage analytics in two ways:

* **Monthly email**: Okta sends a summary report to your registered technical contact. The email provides a high-level snapshot of your integration's health, including the metrics in the previous table.
* **OIN Wizard dashboard**: Click the link in the report email to view the dashboard. You can also sign in to your Integrator Free Plan org, go to the OIN Wizard, and click **Analytics** on the **Your OIN Integrations** page. The dashboard shows the same report data as the email.

If you have more than one app in the OIN, select an app from the **Select an app to view analytics** dropdown list to view the metrics for that app.
