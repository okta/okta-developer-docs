If your tokens expire in the XAA flow, you can request for another token depending on the condition of the token:

* When the resource access token expires, you can reuse the ID token to perform another ID-JAG token exchange. See [Token exchange for ID-JAG](#token-exchange-for-id-jag).
* If your ID token has expired, obtain a new ID token by having the user sign in through SSO again. See [User SSO](#user-sso).
